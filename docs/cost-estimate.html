Model Assumptions

  • ~80% approval rate (most requests approved)
  • 8 Lambda invocations per request lifecycle
  • Lambda free tier: 1M invocations + 400K GB-seconds/month (permanent)
  • 10 API Gateway calls per request (submit, approve, start, status polls, log, dashboard)
  • 7 DynamoDB writes + 5 reads per request
  • 1 Bedrock call per request after log arrives (risk re-score)
  • Bedrock: ~2,500 input tokens + ~250 output tokens per call
  • Claude Haiku 4.5 pricing: $0.0008/1K input, $0.004/1K output
  • Risk scores cached 48h per user — repeat users reduce Bedrock calls
  • EventBridge: 2 schedules per approved request (warning + expiry)
  • CloudFront + S3 within free tier at this scale
  • Does not include: KMS ($0 within free tier), CloudWatch Logs (free tier), Route 53, WorkMail (not this project)

This estimate uses account-wide AWS pricing as of April 2026. Actual costs will vary based on session duration, unique users (Bedrock caching), and IT dashboard usage. Enable cost allocation tags (Project=temp-admin-access) in AWS Billing to track actual spend once tags propagate (~24h).
